# ETKN TV

ETKN 原生 Android TV 客户端。Android 7（API 24）及以上，遥控器操作，内置 AndroidX Media3 播放器。

## 首版功能

- 自动发现局域网 ETKN 媒体服务器，探测 8097/8096，并通过 5257 管理入口读取实际媒体地址；支持自定义媒体端口和 Docker 映射。也可手动填写媒体服务器地址，登录前核验实例身份。
- 用户登录、媒体库浏览、搜索、季集选择、续播、播放进度同步、音轨和字幕选择。
- 详情页默认聚焦播放/继续播放，支持多版本、音轨与字幕预选并传入播放器；背景和 Logo、同尺寸图标双评分、题材标签、时长、分级与演员表。演员可进入人物介绍和关联媒体，详情显示更多类似。单季直接显示集号矩阵，多季可切换；首页继续观看的单集也能浏览同剧其他集。
- 媒体库海报墙无限滚动分批加载，进入时回顶；显示库名、数量、内容及来源类型。排序覆盖列表接口现有选项，TMDb/豆瓣分别排序；海报底部渐变双评分、右上集数角标按服务端配置显示，片名与年份居中两行。
- 首页顶部菜单默认隐藏，按 ↑ 唤出、按 ↓ 或返回收起；全屏背景随遥控器焦点切换，继续观看、媒体库、最新入库依次排列。继续观看卡片缩至 192×150dp、贴近底部，点击直接续播；背景简介最多两行，焦点边框轻微呼吸。
- 首页数据和图片按账号缓存，优先显示本地内容并在线校验。前台接收服务端专用实时更新通知，合并刷新并保留焦点；返回首页及每分钟补充校验。背景图片独立加载，可见卡片才请求图片。
- 海报、横幅、焦点背景、Logo 与头像均使用圆角显示；首页轮播、焦点背景及详情背景统一叠加更深的灰色遮罩，降低背景亮度，不使用渐变。
- 首页“最新”按媒体库的“显示在最新媒体库”开关分别呈现，并使用媒体库名称作为分区标题；关闭开关的片库不显示。
- 在首页顶部菜单聚焦当前用户头像并按确定，可切换本机已登录用户或登录新用户。账号凭据由 Android Keystore 加密，只支持当前 ETKN 媒体服务器。
- 全屏焦点背景优先使用影片背景图及 Logo；剧集缺少 Logo 时显示剧名与季集号、集标题。没有继续观看记录时，初始焦点落在第一个媒体库。
- 显示 ETKN 本地用户头像；在网页个人中心上传。
- 有效 Plus/Pro 实例及获模板权限的普通用户可使用影视探索、季度订阅、共享池/re0/频道搜索与确认获取；服务端最终鉴权，管理员沿用服务端权限。
- 可选“我的订阅 / 追更入库通知”，默认关闭；只匹配该账号有明确来源归属的订阅，并过滤片库/路径/分级权限。季度订阅按季度匹配，系统全局追剧记录不会冒充个人关注。首次开启建立基线，不补发历史入库。前台约每分钟检查，后台由 Android 调度（15 分钟周期，可能延迟），电视系统可能限制通知展示。
- 从本仓库 Releases 检查、下载、校验并安装更新。校验包名、版本、SHA-256 和当前安装签名，安装由系统确认。
- 每个媒体库独立保存排序，重启后恢复；退出媒体库时焦点回到原媒体库卡片。
- 播放全屏，左右键及快进/快退键只显示进度条，停止操作 5 秒后隐藏；按遥控器 ↓ 唤出完整控制栏。音轨/字幕沿用服务端完整列表，优先显示副标题并去掉默认标记；无法可靠对应或解码的条目明确提示。文本字幕使用透明背景和黑色描边。
- 中间整组原生控件全部移除，播放/暂停使用遥控器确认键；上方控制栏默认聚焦“下一集”，按季号、集号跳到下一可用集，季尾继续下一季。切集后按目标季恢复音轨序号锁定，电影和全剧最后一集隐藏下一集，控制栏回退聚焦音轨。
- 手动选择“第 N 音轨”后，当前剧的当前季记住该列表序号，退出或重启仍有效；不依赖可能错标的标题、语言或各集轨道 Index。某集缺少该序号时提示并按默认播放，保留本季锁定；选择“自动选择（解除本季锁定）”可恢复自动策略。
- 分集矩阵铺满可用宽度，从外部进入时默认定位续播集，没有续播则第一集；从具体单集打开时定位该集。已观看集使用绿色背景和勾，续播集使用按比例填充的绿色进度。
- 默认音轨/字幕优先级与网页个人中心同步，个人配置覆盖全局，清空后跟随全局。片头片尾可选显示跳过按钮、自动跳过或关闭，只使用媒体版本的明确标记。

下载：[最新发行版本](https://github.com/hbq0405/etkn-tv/releases/latest)

v0.1.0 / v0.1.1 若在应用内更新时提示“更新包签名不符”，请从 Releases 下载 v0.1.2 或更高版本 APK，手动覆盖安装一次，保留原 App 和数据。旧版更新器存在证书读取兼容问题。

## 服务端

需要包含个人推荐、用户头像、个人订阅入库通知、来源上下文迁移 0175 和 `/api/system/tv-discovery` 连接信息接口的 ETKN 版本。v0.1.0 升级至 v0.1.1 及以上后需重新登录，以校正旧版保存的管理入口。v0.1.2 升级至 v0.1.3 后，头像菜单可切换本机同一 ETKN 服务器的已登录用户或添加账号。
v0.1.8 起，登录、片库、详情、图片、剧集和播放调用 ETKN 专属 `/api/tv` API；影视探索调用 `/api/tv/discover` 并由服务端最终鉴权。安装 v0.1.8 前先更新 ETKN 服务端以提供该 API。第三方 Emby/Jellyfin 客户端仍使用原兼容接口。非本地媒体使用 ETKN 直链/302，不添加流代理或转码。账号密码不落盘，会话令牌以 Android Keystore 加密。

v0.1.15 的首页实时缓存更新需要服务端 `/api/tv/Users/{user_id}/Home/Events` 及通知迁移 0176；旧服务端仍通过进入首页和每分钟在线校验更新。

发行 APK 为通用包，包含 ARMv7、ARM64、x86、x86_64 原生库。ExoPlayer 保留设备视频硬解，增加 FFmpeg 音频解码与软件视频回退；10-bit HEVC 在 JNI 中转换为 8-bit YUV420P 后再写入 YV12，兼容 stride=0 的电视/模拟器窗口。ASS 使用 libass/Canvas 渲染并限制字幕渲染面积为 1080p，异常时降级普通字幕；PGS 支持多对象、分片复用与外挂 SUP 时间戳。杜比 P7 在提取阶段声明 HEVC 基底层，音频/视频错误独立回退。网络使用 OkHttp 连接复用，缓冲同时限制时长和内存。软件解码性能仍受设备及分辨率影响；不添加服务器转码或媒体流代理。

## 构建与发行

GitHub Release 正式发布后，工作流 `TV Release Telegram Notification` 向配置的 Telegram 群发送 TV 版本、更新说明和下载链接。仓库 Secrets 为 `TELEGRAM_TOKEN` 和 `TELEGRAM_TO`；草稿不发送，通知不置顶。成功日志保留消息 ID，成功后不要重复运行以免重复通知。

JDK 17 以上、Android SDK 36（Build Tools 35）、Gradle Wrapper 8.13。

```powershell
$env:JAVA_HOME='你的 JDK 目录'
$env:ANDROID_HOME='你的 SDK 目录'
.\gradlew.bat :app:assembleDebug :app:lintDebug :app:testDebugUnitTest
```

发行使用固定签名，在私有目录创建 `signing.properties`，字段为 `storeFile`、`storePassword`、`keyAlias`、`keyPassword`，将绝对路径放入 `ETKN_TV_SIGNING_PROPERTIES` 环境变量。私钥和属性文件不入 Git，须另行安全备份；后续更新必须沿用同一签名，递增 versionCode。

```powershell
$env:ETKN_TV_SIGNING_PROPERTIES='本机私有目录\signing.properties'
.\scripts\Build-Release.ps1 -OutputDirectory '发行输出目录'
```

检查生成的 APK、update.json、SHA256SUMS.txt 和说明，之后通过 `gh release create v<版本> <发行文件> --repo hbq0405/etkn-tv --notes-file <说明文件>` 发布。源码与发行包均在同一公开仓库。

## 验证范围

首版经过后端定向回归、生产回滚验证、Android 单元测试、Lint 和签名构建。未接入电视设备，遥控器焦点、电视硬解码兼容、字幕效果、系统通知及安装更新流程须实机验收。播放器按设备实际支持的格式播放，不承诺所有编码都能硬解。

v0.1.8 已在 Android TV 模拟器上通过真实首页的 37 个焦点位置回归，覆盖上下片架及横排行首、行尾的聚焦图片完整性。真实电视播放、系统通知与安装更新仍须实机验证，详见 [v0.1.8 验证记录](docs/2026-10-28-tv-api-and-focus-0.1.8.md)。

v0.1.12 的 23 项模拟器回归覆盖页面、遥控器焦点、排序持久化、个人偏好、跳过标记和真实合成媒体解码。AAC/AC3/EAC3/DTS/立体声 TrueHD 实际输出音频缓冲，软件 HEVC 与 4K 10-bit HEVC 实际输出画面，ASS 连续快进后仍有非透明字幕像素；VC-1 测试在未提供私有片段时按规范跳过。详情见 [v0.1.12 验证记录](docs/2026-10-29-player-and-tv-0.1.12.md)。模拟器没有音频输出设备，不能代替电视扬声器、真实片源或高码率字幕性能验收。

v0.1.14 迁移柴柴已核实的 Media3 策略，固定原有 Media3/NextLib/libass JNI。Debug/Release 单测各 30 项；完整仪器回归 30 项，29 通过、VC-1 素材缺失跳过 1 项。增加多对象 PGS/SUP、真实播放器 seek/字幕异常恢复、ASS Canvas 和 P7 提取格式检查；实际电视 P7 解码及复杂 PGS 性能仍需实机验证。详情见 [v0.1.14 验证记录](docs/2026-10-29-player-compatibility-0.1.14.md)。

v0.1.15 的 Debug/Release 单测各 31 项、Lint 与签名构建通过；完整模拟器回归 36 项，35 通过、VC-1 素材缺失跳过 1 项。覆盖首页缓存和更新事件、直接续播、季音轨序号锁定、透明字幕及分集状态/入口/宽度，详见 [v0.1.15 验证记录](docs/2026-10-29-home-and-season-audio-0.1.15.md)。真实电视性能和安装更新仍需实机验证。

v0.1.16 的 Debug/Release 单测各 32 项、Lint 与签名构建通过；完整模拟器回归 39 项，38 通过、VC-1 素材缺失跳过 1 项。随后调整默认焦点，最终控件定向回归 6 项全部通过，覆盖默认聚焦下一集和延迟结果不抢焦点。新增下一集遥控器操作、切集进度上报及跨季音轨锁定；通知流程本地 6 项验证通过。详见 [v0.1.16 验证记录](docs/2026-10-29-controls-and-release-0.1.16.md)。
