# ETKN TV 0.1.107

本版汇总 0.1.99 之后的个人偏好同步、音乐库、逐项随机推荐和登录品牌更新。

- 首页个人推荐每次进入重新随机，从最多 500 个候选中逐项获取；首项准备好即可显示，仅提前准备下一项的背景图、Logo 与元数据。缺少背景或图片加载失败时跳过，下一项未就绪时保持当前画面；切换后继续准备下一项，移除手动切换，更新通知不重新打乱顺序。
- 账号外观、卡片大小、播放和首页偏好与 Web 双向同步，支持主题色、阴影色预设及 RGB 调色，并接收 Web 设置的账号背景。“锁定偏好”按电视、服务器与账号保存；解锁后恢复同步。
- 管理员可独立同步“保存管理员账号”，不受锁定偏好影响；关闭保存后保留当前会话，下次登录需重新验证密码。
- 新增 TV 音乐库与全屏播放页，分类保留推荐、专辑、歌手、文件夹、歌单。顶部按上键打开主菜单，返回或下键恢复原焦点；最新专辑单行横向浏览，最近听的与 Web 使用同账号记录。
- 点击专辑按服务端曲序播放首曲，长队列继续分页加载。播放页左侧显示封面与图标控件，右侧每首歌曲保留独立卡片、时长和动态播放标识；焦点离开队列后隐藏边框。循环图标以 ALL / 1 区分列表和单曲循环，遥控器返回停止播放并退出。
- 登录页和用户选择页显示 ETKN Logo 与真实服务器名称，两者随当前主题色动态更新，Logo 保留透明镂空轮廓；启动预览默认暗色。
- 修正剧集新增版本通知，已有剧集新增版本显示“已更新”。

个人偏好、音乐与逐项推荐需配套已更新的 ETKN 服务端。沿用固定正式签名，可覆盖安装保留数据，支持 Android 7 / API 24 及以上；版本代码为 108。

正式签名构建、113 项 Release 单元测试及 Lint 零错误通过；登录 Logo 已验证深浅色、动态换色及镂空像素。已在用户电视覆盖安装并核对版本、APK 哈希、启动及当前主题 Logo；真实账号下的推荐与音乐长期体验仍待使用确认。

应用对应源码为本仓库 `v0.1.107` 标签。原生播放器依赖、源码与重建脚本未变，继续复用 [0.1.80 原生播放器源码包](https://github.com/hbq0405/etkn-tv/releases/download/v0.1.80/etkn-tv-player-sources-0.1.80.zip)，包含依赖源码与原始许可；应用按 GPL-3.0 发布。
