# ETKN TV 0.1.27 播放路径回退

日期：2026-10-30。用户授权修复、本地提交、模拟器验证和原签名 APK 构建；未推送、未发布。

## 目标与结论

用户实测 0.1.26 后反馈无画面，软件解码也严重卡顿。该版本的模拟器通过没有覆盖 L055FCN 的实际回归，因此撤回 0.1.26 的旋转方案，恢复用户已确认软件解码正常的 0.1.25 播放路径。0.1.27 是恢复基线的版本，原 OMX 270° 旋转问题仍未修复，真机恢复情况仍待安装验证。

## 实际变更

- PlayerActivity、TvVideoRenderer、player_texture.xml 和对应仪器测试恢复到提交 `1a87269`；删除 RotatingPlayerView。
- 系统解码恢复 SurfaceView 与 MediaCodec 自身旋转；软件解码恢复普通 PlayerView 的 TextureView 与原始帧旋转矩阵。
- 撤回运行时输出视图切换及强制零旋转，保留 0.1.25 的首页仅聚焦续播、播放结束退出、停止回报幂等和 FFmpeg 亮度拷贝修复。
- 版本递增为 0.1.27 / versionCode 28；没有修改原生库、服务端或依赖版本。
- 更新开发边界、构建规范和 0.1.26 记录，注明真实回归与撤回，避免把模拟器结果当作厂商兼容结论。
