## 面向用户的更新说明

- 电视外观跟随服务器，并可按账号锁定自己喜欢的主题。
- 暂停或打开控件显示头像和时间；功能键切音轨，长按确认键查看影片信息。
- 优化卡片阴影、首页背景、登录明暗、季海报和分集按钮。
- 加载、入库和跳片头片尾提示更统一，预缓存进度更容易区分。
- 修复部分原盘音轨、字幕切换及快进快退后的问题。

完整中文说明以 Release 正文及 `release-notes.md` 资产为准。服务器外观同步和原盘修复需要配套已更新的 ETKN 服务端。
