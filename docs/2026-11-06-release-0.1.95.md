# ETKN TV 0.1.95

本版合并 0.1.88 之后的详情、订阅、云资源搜索和遥控器界面调整。

- 片库电影和剧集详情进入即可看到演员表，一行完整显示 8 位演员，头像保持 2:3，更多演员左右浏览；仅头像参与焦点放大，确认可进入人物详情。
- 压缩 Logo 与操作区，把类型、标签、合集和工作室并入评分行，分级与类型之间留出间距。简介固定三行，聚焦确认查看全文。
- 主页新增“选集”入口，季列表与分集移至独立页面；返回保留当前集、版本、音轨、字幕、进度和入口焦点。
- 影视探索详情采用纯色背景与更大海报，操作按钮置于简介之前，演员信息同屏展示。
- 订阅时弹窗选择单季或订阅全部缺失季，已入库及已有订阅的季自动跳过；探索剧集资源搜索按全剧查询。
- 剧集共享池资源按季分组，re0 与频道展示资源说明；移除重新搜索输入框，资源页面四周保留边距。
- 调整顶部菜单、按钮与用户选择入口；改善首页后台刷新时的焦点保持，以及播放返回后的详情进度刷新。

沿用固定正式签名，可覆盖安装保留数据。Android 7 / API 24 及以上，通用 APK。继续使用现有 ETKN TV 接口，本次不包含服务端更新。

99 项单元测试、Release Lint 与签名构建通过；已在 L055FCN / Android 9 电视完成相关界面和遥控器定向回归，0.1.95 已覆盖安装并核对启动。订阅与资源获取回归使用合成服务，实际账号全流程仍以使用结果为准。

应用对应源码为本仓库 `v0.1.95` 标签。原生播放器依赖、源码和重建脚本未变，继续复用 [0.1.80 原生播放器源码包](https://github.com/hbq0405/etkn-tv/releases/download/v0.1.80/etkn-tv-player-sources-0.1.80.zip)，包含依赖源码与原始许可；应用按 GPL-3.0 发布。
