## 功能

- 账号外观、卡片大小、播放和首页偏好与 Web 双向同步；支持主题色/阴影色预设和 RGB 调色。TV 不提供背景上传，接收 Web 保存的账号背景。
- “锁定主题”改为“锁定偏好”，冻结全部共享偏好及私有背景副本，禁止修改、暂停同步并忽略在途响应；解锁立即恢复服务器最新偏好。
- “保存管理员账号”通过独立账号接口同步，不受锁定影响。保留原有登录语义：取消保存只清除持久凭据，当前会话保留，下次恢复需密码；恢复前在线读取服务器开关，旧客户端迁移不得覆盖服务器明确的关闭状态。
- 首页增加显示媒体库选项，音乐库提供推荐、专辑、歌手、歌曲、文件夹、歌单、收藏和常听。两端都增加“最近听的”，与常听保持卡片样式一致。
- 音乐使用全屏播放页：左侧封面/信息/遥控控制，右侧分页队列；支持播放模式、暂停恢复、上下首、进度及播放回报。TV 频谱明确延期。
