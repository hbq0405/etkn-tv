# 文件夹少量媒体海报墙修复与卡片信息缩放 0.1.74

## 问题与原因

用户使用年份目录，某年份中只有一部电影时出现一张巨大图片，无法看到正常海报墙。正式签名隔离包在模拟器复现：正常满行的极小竖幅卡片宽 196px，同目录只保留一项时被放大为 1736px。根因是共用 Android GridLayout 的 columnSpec 拉伸权重为 1 且卡片宽度为 0；不足一行时按已存在的条目分配全部空间。

## 实际修改

- TvActivity.java：移除自适应网格卡片的拉伸权重，以可用宽度/整行列数减去实际左右间距确定列宽。新增卡片与重排使用相同几何，宽度改变即使列数未变也重算。文件夹、普通媒体库、合集、分类与探索页共用修复，未增加占位卡片或专属分支。
- TvActivity.java：横竖幅未看/总集数角标、竖幅片名与年份、双评分、图标、评分区域及代表性间距均按卡片实际宽度等比例缩放。横幅片名避让角标使用实际角标宽度与同比间距，放大后仍不重叠。计数与播放状态语义不变。
- HomeFocusTest.java：增加文件夹 1/2 项与满行相同列宽的横竖幅五档真实布局回归，扩展既有缩放指标；文件夹/分类旧固定 dp 宽度断言改为实际自适应列宽。Fixture 子媒体提供真实合成海报。
- DiscoveryFlowTest.java：宽度变化后等待图片比例布局完成；只剩一项时断言保持原列宽及左侧位置。
- app/build.gradle：0.1.74 / versionCode 75。媒体库横幅继续只用文字片名，无 Logo 请求；极小/小/中/大请求 360 背景，极大请求 720。服务端无修改、无部署。
