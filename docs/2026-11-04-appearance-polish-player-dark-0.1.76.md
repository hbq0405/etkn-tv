# 0.1.76 外观衔接、登录明暗与暗色播放器

日期：2026-11-04（Asia/Shanghai）。用户授权修改后 ADB 更新指定电视，未要求推送或发布。

## 变更

- 卡片阴影轮廓固定独立于卡片底色透明度，修复服务器透明度为0时阴影一起消失；普通4dp、聚焦8dp仍乘服务器阴影强度，0时没有阴影。公共行列允许阴影越界，保持卡片尺寸与焦点缩放。
- 首页轮播图片及媒体灰色遮罩在下方55%区域逐步渐隐，底部透出服务器背景；文字、Logo、按钮在渐隐层外。保留320ms切换与模糊未完成时不露出清晰图片的规则。
- 服务器壁纸删除固定明暗遮罩；模糊强度0直接复用原始图片，不再额外模糊或罩白/罩黑。此项覆盖普通页面和起播等待；媒体详情与轮播自己的媒体遮罩沿用既有规则，轮播底部随图渐隐。
- 在Activity初始化前应用缓存明暗；登录密码和切换用户弹窗显式选择当前明暗主题，已打开弹窗动态更新文字、输入提示及背景，保持输入、焦点、账号验证语义。
- 动态AppearanceShape禁止返回普通GradientDrawable的ConstantState，防止Android复制后丢失动态颜色。公共Button和EditText清除系统背景染色，实际截图已验证深色密码输入框恢复暗色。
- 播放器及音轨/字幕/版本/倍速/解码弹窗、分集面板、媒体信息固定暗色；按Activity局部解析，不改写服务器全局明暗，不影响返回页面。主题色、透明度、阴影、壁纸及模糊仍读服务器。
- 控制栏移除胶囊背景及外框，按钮常态透明，焦点仍显示主题色轮廓，保留片名、两侧留白、进度、头像、时间、暂停符号、功能键音轨和长按确认媒体信息。
- 版本0.1.76 / code77；无服务端源码或部署变更。
