# v0.1.16 播放控件与 TV 发版通知

## 实际变更

- 通过固定 Media3 1.8.0 的 PlayerView 显示开关，隐藏中间上一项、下一项、快退、快进四键，保留播放/暂停和进度。上方自定义操作栏增加“下一集”，不修改已有遥控器快进退逻辑。
- 详情和直接续播入口传入 SeriesId。分集列表由 TV 专用 API 在后台独立读取，不阻塞 PlaybackInfo 和起播；普通查询失败只隐藏下一集，鉴权错误沿用会话退出逻辑。
- 按季号、集号选择下一可用集，跳过缺失和 Virtual 占位，不依赖服务端返回顺序或标题；季末跨下一季。电影和全剧最后一集隐藏按钮。
- 切换先停止并上报旧集，再启动新播放器、结束旧页面，避免返回栈累积。新集从开头播放、使用服务端首选版本；按目标季恢复已保存的音轨列表序号，保留既有缺轨回退。播放结束不自动跳集。
- 新增 GitHub Release `published` 通知工作流。版本、说明和下载链接从事件 JSON 读取，正文以纯文本发送并限制长度，保留下载链接；不将正文插入 shell。只使用仓库 Secrets，错误日志不回显带凭据的 API 地址；成功须有 Telegram message_id。

## 复用规范

- 发行前先检查草稿正文和全部资产，转正式后检查通知 Actions 与 Telegram message_id；成功的通知任务不要重复运行，避免群内重复消息。
- 机器人凭据和群配置只保存在仓库 Secret，禁止加入源码、说明或归档。此工作流无额外测试发送或置顶。
- Media3 的原生 Next 是播放列表导航，当前播放器每次只有一个 MediaItem；真实剧集下一集应通过已鉴权的 TV 分集列表查找。
