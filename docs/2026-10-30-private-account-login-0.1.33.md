# 私密账号和管理员重新登录（0.1.33）

日期：2026-10-30。版本：0.1.33 / versionCode 34。配套服务端 ETKvNext 迁移 0177。

## 目标与行为

- 私密账号的身份、名称和令牌只保存在当前前台会话内存，不写入会话偏好或账号列表。退后台后销毁临时会话，热返回需要重新输入用户名和密码；切走后也不能从账号列表直接恢复。
- 管理员只保存账号 ID 和名称，不保存密码和令牌。热返回、切换到管理员及再次选择当前管理员均需输入密码。取消或密码错误不完成切号。
- 普通账号继续保存 Android Keystore AES/GCM 加密令牌，沿用现有账号顺序和登录方式。
- 受限会话窗口设置 FLAG_SECURE，退后台隐藏旧界面；播放页未通过门禁时不恢复播放。登录前不开始通知轮询，私密会话退后台取消通知。
- 密码输入关闭状态保存和自动填充，提交后及页面退后台清空。受限账号拒绝空密码登录，提示先设置密码。

## 关键实现

`SessionStore` 分为完整保存、仅账号、完全不保存三种策略；管理员和私密账号保存前同步移除旧凭据，写入失败时拒绝完成登录。`SetupActivity` 恢复前通过各已保存账号自己的令牌查询 `/api/tv/Users/Me`，旧私密账号从列表移除，旧管理员令牌清空。网络失败不直接使用旧令牌恢复。

`LoginGate` 的代次在整个应用退后台时变化；网络请求结束和界面成功回调均检查代次，防止迟到登录响应在退后台后重新建立临时会话。Home 切号与 Setup 共用同一验密入口。
