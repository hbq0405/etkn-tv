日期：2026-11-12。目标为开机自动进入，Home 返回原生桌面；保留 IMDb 评分/排序和详情工作室文字。用户已授权将本版推送并发布，发布验收另行记录；以下为发布前构建与实机证据。

## 根因与最小修复

0.1.110 的开机接收器仍启用，应用没有 stopped 标记，但冷启动后进程没有运行。当前固件的 `BroadcastQueue.processNextBroadcastLocked` 在需要新建进程时调用 `isDataApp`，丢弃第三方应用广播。仅增加广播 action 不能解决这个限制。

0.1.111/code112 增加开机专用 `BootStartupService`，由系统辅助服务绑定使进程接收标准 BOOT_COMPLETED，并兼容本固件 FAST_BOOT action。服务不订阅无障碍窗口事件、不能读取窗口，实机 eventTypes=0、capabilities=0；没有 Home 接管。应用内开关仍默认关闭，广播接收器须按本机选择启用。标准开机按 boot count 去重，同次开机30秒内重复事件忽略；启动沿用普通 MAIN/LAUNCHER 与 NEW_TASK/RESET_TASK_IF_NEEDED，不清空任务。

本机已合并启用开机辅助服务，保留其他辅助服务配置；没有改用户账号或登录模式。用户当前选择登录用户，故自动进入账号选择页符合现有设置。

## 适用边界

实际验证仅覆盖这台 FengOS L055FCN/Android 9 的重启、遥控器关机后冷开机和 Home。此次遥控器关机开机增加 boot count，不能据此证明同一 boot 下的快速待机唤醒；FAST_BOOT 仅代码分支验证。

普通 Android 开机广播路径仍保留，其他电视可按本机开启开机开关后测试，但不能承诺所有机型有效。本次在系统中启用开机辅助服务是设备配置，不会随 APK 自动带给其他用户；这台 FengOS 必须同时启用开关和开机辅助服务。其他厂商的后台启动管理、辅助服务入口与新版系统的后台 Activity 拉起能力须实机核验。本轮外网官方文档检索未返回可用内容，因此兼容性结论仅限源码路径和本机实测，不据文档推断其他电视已经可用。
