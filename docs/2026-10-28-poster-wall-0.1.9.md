# ETKN TV v0.1.9

- 首页与媒体库卡片横向间距加大，聚焦后保留间隔。
- 进入媒体库海报墙从顶部开始；滚动接近底部自动加载下一批，全部加载后停止请求，无翻页按钮。
- 左上显示媒体库名称、媒体项总数、内容类型和来源类型，右上支持列表接口现有排序及升降序，TMDb/豆瓣评分分别排序。
- 海报底部渐变双评分：绿色豆瓣标记、TMDb 五角星；右上角按服务端配置显示总集数或未播放集数。
- 海报下方居中显示片名、年份两行。

需要先更新 ETKN 服务端，新增字段及评分排序通过独立 `/api/tv` API 提供。

验证：22 项发行单元测试、Lint（0 errors，27 warnings）及固定签名发行构建通过；Android 16 TV 模拟器 2 项仪器测试通过，覆盖首页 37 个焦点位置、媒体库回顶、豆瓣排序、60→120 项追加和末页停止请求。使用合成服务截图并目视确认。真实电视播放、遥控器与系统安装更新仍需设备验收。
版本：versionCode 10，最低 API 24、target API 35。签名 SHA-256：e02d42443875c3631be48199e0df419b0570fcc421be7ff2b620f4c643e67bd7，与 v0.1.8 相同。
