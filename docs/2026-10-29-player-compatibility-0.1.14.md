# ETKN TV 0.1.14 播放兼容验证

## 目标与证据范围

迁移用户提供的柴柴 0.3.2-alpha4 APK 中可核实的 Media3 播放策略，处理解码兼容、特效字幕和轨道标题。生产播放记录与媒体分析只读查询确认，反馈中的《特种部队：蛇眼起源》为 HEVC Main10 / 杜比视界 P7，《007：大破天幕杀机》的内封特效字幕为 PGS。服务端没有电视解码异常堆栈，不能据此认定唯一根因。

柴柴仓库没有可直接构建的播放器工程；本版按已核实调用顺序和策略实现适配，PGS 的颜色转换/Cue 布局保留 AndroidX Apache 版权声明。保留 Media3 1.8.0、NextLib 与 libass 原生库，没有迁移 MPV、音频延迟/直通配置或整套 UI。

## 实际变更

- TvPlayerFactory 统一网络、缓冲和字幕工厂；OkHttp 连接 30 秒、读取 10 秒，最多 5 个空闲连接保留 5 分钟。鉴权保留在同源 URI，不给 CDN 追加 ETKN 认证头。
- 缓冲最低/最高 50/120 秒，起播 2 秒、重缓冲 5 秒、回看 12 秒；按时间或目标字节先到停止。普通设备目标 64MiB、低内存设备 32MiB；这是本项目适配值。
- 多对象 PGS：对象定位、裁切、分片、调色板/对象复用、zlib、清屏和 reset；支持外挂 SUP 的 PG/90kHz 时间戳。缓存压缩数据上限 16MiB、对象最多 64 个、每次输出像素预算 3840×2160；异常数据跳过。
- ASS 使用 Canvas，保留 1080p 渲染面积限制；初始化或运行异常时重建普通字幕链路。PGS 继续使用同一解析器，恢复可寻址媒体的位置及所选轨道。
- 在提取器 TrackOutput.format 中把 P7 声明为 HEVC 基底层，再进行轨道选择；P5/P8 不在此处改写，既有解码器兼容逻辑保留。这不是视频转码，也不证明保留完整杜比视界效果。
- 音频失败尝试系统解码，视频失败才回退软件视频，字幕错误进入字幕降级；不再按 4001–4005 错误码把音频/字幕错误当成视频故障。
- Title（副标题）优先，空白时使用 DisplayTitle；移除既有默认标记后仅在自动选择项追加一次默认。详情和播放菜单统一。
- 保留 0.1.13 的首页轮播、焦点背景、详情背景调暗，以及快进/快退仅显示独立进度条。

## 验证

- 标题回归在旧实现先出现 3 项失败，修复后通过。Debug 和 Release 单测各 30 项，0 失败；两种 Lint、签名发行构建通过。
- Android TV API 36 / x86_64 模拟器完整仪器回归输出 OK (30 tests)。逐项状态为 29 项通过、1 项 assumption 跳过、0 失败；跳过项是未提供私有 VC-1 素材。
- 相同 PGS 合成数据，默认解析器返回 1 个对象，新解析器返回 2 个；覆盖压缩、分片、复用、清屏、seek reset、损坏 RLE、超大对象和 SUP 时间戳。
- 真实 ExoPlayer 管线选择外挂 PGS，检查两个 Cue、seek、模拟字幕错误后仍显示两个 Cue，播放位置继续超过 5.7 秒，字幕 Index 保留，视频模式不变。ASS 有可见动画像素，注入字幕错误后恢复普通文本。
- AAC/AC3/EAC3/DTS/TrueHD 切轨、seek 后实际输出音频缓冲；HEVC 软件解码、4K 10-bit HEVC 实际输出画面。未仅以 supportsFormat 判定成功。
- 完整回归还覆盖方向键/媒体快进键、仅进度条、返回/下键、自动隐藏、详情轨道与首页导航。已提取并目视核对 PGS 双对象、ASS Canvas、快进进度条和 4K 画面截图。
- 两处测试素材问题已保留证据并修正：外挂使用带时间戳 SUP，位置恢复使用有索引的媒体；4K 中央窄裁区误报单色后，核对截图和实际颜色范围，保留原门槛并扩大至横跨色条的居中区域。过程见构建 SOP。
- APK 内 16 个原生库与 0.1.13 逐字节相同；源码包 17 个档案均通过清单 SHA-256 和 ZIP 完整性检查，新增 OkHttp/Okio 源码及许可通知。
