## 同一模拟器对照

60 张不同 URL 的 1066×600 图标，逐行访问全部卡片后，用相同上下方向键路径采集 FrameMetrics。位图占用统计页面持有的全部 Bitmap，不代表整个应用总内存；按键统计为仪器注入返回并完成主线程检查的耗时，不是端到端显示延迟。

| 指标 | 修改前 | 最终第一次 | 最终复测 |
| --- | ---: | ---: | ---: |
| 60 张 Bitmap 字节 | 153,504,000 | 23,362,560 | 23,362,560 |
| 绘制帧 P50 毫秒 | 35.85 | 34.56 | 34.41 |
| 绘制帧 P95 毫秒 | 69.40 | 50.71 | 39.88 |
| 按键检查 P95 毫秒 | 36.22 | 26.36 | 24.84 |

单独缩图时 P95 仍约 70.68ms，因此没有只凭内存下降宣称焦点延迟已修复；最终还关闭分类页平滑滚动，并隐藏成功图标下的占位文字。模拟器数据存在波动，不能替代真电视体感。
