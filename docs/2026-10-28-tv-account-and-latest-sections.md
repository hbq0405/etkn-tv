# ETKN TV 账号切换与媒体库最新分区

## 实际变更

- 首页菜单头像现在可通过遥控器聚焦并打开用户列表，可切换本机已有登录用户，也可登录新用户。
- 原有 Android Keystore AES-GCM 加密方式保留。活动账号切换只替换当前会话；首次读取账号列表时迁移现有单账号会话。退出或令牌失效移除当前账号，其他已保存账号不受影响。
- 登录新用户固定使用已配置的 ETKN 媒体服务器；如试图使用不同服务器，在发送认证信息前拒绝。未实现多服务器账号配置。
- 所有 App ImageView 均有圆角裁切：海报/横幅、轮播背景与 Logo、用户头像。头像使用圆形裁切。
- 首页“最新”改按 `/emby/Users/{id}/Items/Latest?ParentId=library-*` 单独查询媒体库。ETKN 已经按 `definition_json.show_in_latest` 返回库级最新项，开关关闭的库为空，当前用户片库权限由服务端继续控制。非空分区显示“最新+媒体库名称”。
- 轮播图底部增加渐变至首页 `INK` 背景的遮罩，让图像渐隐到继续观看分区的页面底色。
- 发行版本 v0.1.3，versionCode 4，沿用固定发行签名。

## 验证

- 16 项 Android 单元测试通过，包括 3 项保存账号注册表的去重、切换顺序和单账号移除回归。
- `lintRelease` 通过，0 错误、27 警告；`assembleRelease` 与 apksigner v2 签名验证通过。
- APK 元数据：`xyz.etkn.tv`、versionCode 4、minSdk 24、targetSdk 35。
- 构建和服务端源代码检查不替代设备验收；当前没有可用 TV/adb 设备。头像菜单的遥控焦点、图片裁切和轮播渐变视觉仍需电视实测。

## 后续边界

播放页全屏控制栏、详情页背景图、片头片尾跳过模式仍未实现，沿用用户“先完成首页”的范围。
