# 弹幕 emoji 字体

使用 Google Noto Emoji 固定提交 `99701e07d3d1fe1bdbcdb14964547f0fd592966f` 中的 `2D/fonts/NotoColorEmoji.ttf`，CBDT/CBLC 格式，未修改字体。

完整字体只在启用弹幕、创建覆盖层时加载，没有全局初始化、联网下载或后台任务。普通文字由 Android 回退字体显示；主题色应用于文字，彩色 emoji 保留原色。
