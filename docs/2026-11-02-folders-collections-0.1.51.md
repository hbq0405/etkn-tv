# 文件夹、合集与详情入口（0.1.51，2026-11-02）

- 物理媒体库将原合集按钮改为文件夹切换；虚拟库不显示文件夹。
- 按服务器、账号和媒体库保存媒体项/文件夹选择，重开应用及重启电视后沿用；目录层级在进入该库时从根开始。
- 文件夹与合集均分页；返回恢复已加载数量、卡片焦点和滚动位置。
- 分类目录仅从功能菜单手动生成封面，访问不会自动生成；管理员或模板刷新权限可使用。
- 首页使用稳定的标准 boxsets 合集库，排在最后；最新媒体分区排除合集库。
- 详情题材和标签可独立聚焦，进入权限过滤的入库媒体列表；电影详情显示所属合集入口。
- 新增功能使用 /api/tv；题材列表支持名称、添加时间、首播、年份、TMDb、豆瓣和随机排序。
