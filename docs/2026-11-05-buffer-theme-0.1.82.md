# 0.1.82 预缓存进度条随主题配色

用户要求取消预缓存固定浅草绿，采用同色柔化与明暗自适应方案，并通过 ADB 更新到 192.168.31.188。

## 改动

- PixelTimeBar 从当前有效主题色生成预缓存色：通常混白 65%，与已播放的亮度对比不足 1.65 时，逐步混入深灰，并同时保证与未播放的对比至少 1.5。这是本组件的配色阈值，不作为通用可访问性认证。
- 缓存当前主题对应的派生色，主题变化时重新计算；控制栏和快进提示两个进度条共用。已播放继续使用主题色，未播放继续混黑 72%，播放状态、拖动、标记和绘制几何保持原流程。
- 版本 0.1.82 / code 83。AGENTS.md 中固定浅草绿约定同步为自动配色；服务端无需更改。
