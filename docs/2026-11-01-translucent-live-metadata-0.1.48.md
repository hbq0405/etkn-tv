# ETKN TV 0.1.48：半透明面板与通知后实时更新

## 目标与行为

- 功能菜单、详情页图标/音轨/字幕、播放控件、播放选集面板，以及详情页和播放页的分集矩阵统一使用半透明底色。
- 两处分集矩阵共用黑色底层（alpha 105）和绿色进度层（alpha 160）。不调整列数、格子宽高、间距、集号基线、占位日期和焦点边框。
- 详情收到服务器通知后原位更新片名、豆瓣/TMDb评分、年份、时长、分级、分类、简介与图片；当前分集的标题、简介和剧照一并更新。
- 保留播放对象、MediaSources、音轨/字幕选择、按钮实例、焦点、滚动和矩阵实例。
- 用户要求不查询刷新任务状态。客户端继续订阅现有 Home/Events 通知，使用原有鉴权接口读取页面数据，成功后显示“元数据/图片已刷新”，并弹出同文短提示。手动刷新和服务器定时追剧更新使用相同行为。
- 首次连接建立通知基线，相同 revision 不重复提示；250毫秒合并通知，旧请求不消耗新通知的成功提示。每分钟兜底读取没有新通知时不提示。

## 实现边界

详情页旧逻辑已经重新读取详情，但回调只绑定图片；本次增加展示字段和文字控件的原位绑定。只复制展示字段，不覆盖 UserData、MediaSources 和轨道选择。

刷新任务查询的过渡实现已经撤销，客户端不再有对应状态查询和轮询；服务端过渡接口也已撤销。本轮最终没有后端代码、迁移或生产部署变更。此前的服务端整库管理与追更通知热更新不在本轮重复执行。
