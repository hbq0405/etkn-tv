# 片库详情首屏演员与独立选集页 0.1.93

本轮仅修改 ETKN-TV 的已入库媒体详情。电影和剧集打开即显示演员头像与姓名，季列表和分集通过主页的选集按钮进入独立页面。继续复用现有 TV 接口，没有修改或部署 ETKvNext。

## 实际变更

- 详情 Logo 从 88dp 压到 58dp，标题区域从 96dp 压到 64dp；无 Logo 时保留最多两行片名。
- 评分、年份、时长、分级、类型、标签、合集与工作室合并为同一横向行。工作室有图时只显示完整图标，图片缺失或加载失败时只显示名称，继续支持打开对应媒体列表。
- 操作按钮由 64×52dp 缩为 48×40dp，图标由 32dp 缩为 24dp；版本、音轨、字幕和元数据筛选使用紧凑按钮。
- 简介固定占三行，长短文本保持相同高度，超出部分省略；聚焦后按确认弹出完整简介，无简介时不提供空焦点或空弹窗。
- 演员表放到简介之后，章节与更多类似之前。按可用宽度排十位演员，头像保持 2:3；指定电视上为 75.5×113.5dp。更多演员横向浏览，仅头像参与焦点边框、放大和阴影，确认继续进入人物详情；从其他区进入演员时定位首位。
- 主页不再展开季列表、分集预览和矩阵；独立选集页保留季海报、已观看/进度、续播推荐、分集预览与原有遥控矩阵。返回主页带回当前集、版本、音轨及字幕，保持选集入口焦点，并通过既有播放回执刷新进度。
