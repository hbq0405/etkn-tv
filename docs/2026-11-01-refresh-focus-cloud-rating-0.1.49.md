# ETKN TV 0.1.49：实时版本、入库提醒、刷新任务与播放操作

## 最终行为

- 只有当前页面手动提交并取得 `RefreshRunId` 的任务才查询完成状态。普通 SSE、定时追剧、收藏与观看状态变化仍静默更新元数据及图片；播放期间暂停原页面的任务查询与提示，返回后再确认终态。成功、失败、部分失败、取消各有对应提示，终态只处理一次。
- 媒体库上键展开主菜单后阻止下层筛选/海报抢焦点，吞掉触发方向键的重复事件及抬键；下键返回原焦点。迟到的海报请求回调同样不能抢走菜单焦点。
- 播放操作排列为版本、音轨、字幕、下一集、倍速、解码，默认下一集焦点沿用原规则。两种进度条以黄色短线显示片头两端、片尾开始及影片结束，数据缺失或无效时不画线。
- 详情操作行增加云资源搜索图标，按 `can_access_discovery` 显示，管理员身份本身不授予显示资格。进入探索页再次校验权限；电影/整剧使用当前 TMDb 身份，季/单集读取整剧身份并带入当前季。搜索期间保留图标焦点，返回详情仍停在该图标。
- 共享池版本按网页版身份优先级聚合：逻辑组、内容版本键、SHA1、分集 SHA1 清单、资源源 ID。SHA1 去空白并忽略大小写，同版本优先展示可转存源、累计共享源数，不从父壳继承 SHA1/源 ID/文件清单，保留精确获取身份。
- 详情和首页背景信息优先显示 `CustomRating`，空、空白或 JSON null 时回退 `OfficialRating`；服务器通知后原位更新自定义分级，音轨、字幕、焦点及滚动位置保持。
- 延续 0.1.48 的半透明面板、图标操作和等宽等高日期矩阵；今天/明天使用相对日期，后天起显示年月日。
- 播放控件及其版本菜单只显示槽位名，如“版本 · 原盘”；精确剥离服务端视频 DisplayTitle 后缀，保留槽位名内的分隔符。无槽位回退主版本。详情页仍保留完整版本参数。
- 详情通知刷新合并 MediaSources，按源 ID 保留选择及音轨/字幕；分集矩阵和焦点不重建。旧分集迟到响应不能覆盖当前集；菜单打开期间列表变序，确认仍按原选项 ID 映射，防止选错版本。
- 搜索获取前保存服务端目标版本快照；跟踪该获取任务及关联整理、入库任务，只对 verify 成功且实际可播放的变化版本提醒。首次“已入库”、同槽位旧版替换“洗版成功”、增加独立版本“新增版本”。跳过或未验证不报成功，获取、整理或入库失败仍提醒；辅助通知失败不误报入库失败。分批入库先提醒已经可播部分，整条链终态后结束跟踪。
- 手动获取跟踪按服务器/账号隔离，保留最多七天，前台每分钟核查，后台沿用系统周期任务；不依赖订阅通知开关。与订阅/追更提醒共用版本事件去重，通知可点击打开 item-* 详情。普通订阅/追更也返回入库结果类型。

本轮决定覆盖 0.1.48 报告中的“任意通知后提示已刷新”方案。服务端专属状态接口在 `/api/tv` 内，第三方 Emby/Jellyfin 路由与 DTO 未改变。
