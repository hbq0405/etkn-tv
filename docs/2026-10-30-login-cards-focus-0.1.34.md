# 登录选择与首页焦点交互 0.1.34

日期：2026-10-30。版本 0.1.34 / versionCode 35，最低 API 24、target API 35；沿用固定发行签名。

## 实际变更

- 登录前保留主题背景，账号策略检查完成后直接显示登录界面，移除闪现的“重新检查”过渡页。没有保存账号时直接进入表单；已有账号仍先核查最新策略，失败要求重新登录。
- “登录新用户”独立置于账号列表下方，每个账号显式指定向下焦点，按一次 ↓ 即可到达，确认后进入新用户登录。
- 媒体库卡片与首页继续观看统一为 192×150dp，图片区 192×108dp。首页横向卡片净间距从 12dp 增至 24dp；独立媒体库入口网格按 216dp 单元计算列数。库内海报墙和搜索网格尺寸、间距保持原样。
- 焦点边框改为青绿→青蓝流光，含浅青高光，2.4 秒一圈、40 毫秒一帧、3dp 边框。只绘制边框；失焦、隐藏或脱离视图后不持续调度帧。
- 首页仅继续观看聚焦时背景清晰，显示标题/Logo、年份评分及简介。媒体库、最新片架和菜单聚焦时背景模糊、隐藏这些信息，回到继续观看恢复原图与文字。智能轮播开启和关闭遵循相同规则；轮播详情按钮保留操作能力。
- 模糊在后台对最长边不超过 320 像素的采样图执行三轮横纵均值处理，原图不改写；当前首页使用最多 1MiB 的模糊结果缓存。焦点切换不新增图片请求，异步结果只替换仍对应当前图片的视图。

本轮不改服务端；0.1.33 的私密账号/管理员登录保护继续生效。
