# 音乐库遥控导航与图标播放控件 0.1.101

2026-11-11，源码本地提交 `743446d`，未推送、未发布 GitHub Release。按用户反馈修改 TV 音乐界面；本轮未修改后端/Web 或再做服务端热更新。

## 实际行为

- 音乐库顶部只保留推荐、专辑、歌手、文件夹、歌单五项分类，与内容一起滚动。移除页面返回按钮和搜索、排序、播放全部、正在播放等常驻操作栏；新建歌单放在歌单分类内。
- 顶部按遥控器上键唤出应用主菜单，下键或返回收起并恢复原焦点。主菜单显示期间隐藏音乐分类，避免两层菜单叠影。
- 推荐页最新专辑只显示一行，左右键横向浏览；最近听的、最近常听保留原卡片样式。
- 音乐播放页保留左封面与歌曲/专辑/歌手信息、右队列。上一首、播放/暂停、下一首、播放模式、音量和保存歌单都改成图标；队列后续加载也用图标，保留内容描述和遥控焦点。
- 删除播放页返回/停止文字按钮；遥控器返回停止播放、清空当前队列并退出，停止回报沿用既有流程，在途播放响应不得恢复音频。
- 图标使用实际 Drawable 颜色过滤跟随明暗。截图发现仅设置 Button 的 compound drawable tint 未改变自绘图标实际像素，已修正并加入实际像素断言。
