# ETKN TV 0.1.62

`0.1.62` (`versionCode 63`) makes the landscape poster layout match the home library cards at `192 x 150dp`. The library grid now reserves left and right focus-safe space and updates its column count for the smaller cards. Ratings, titles, years, portrait posters, and the saved view preference remain available.

Validation: 83 Release unit tests, Release lint (0 errors), fixed-certificate APK signing, and four Release instrumentation regressions passed. The regressions cover landscape card dimensions, artwork and rating content, horizontal gaps, first and right-edge focus visibility, portrait-view compatibility, the home library cards, folders, and poster pagination. All 20 native player libraries are byte-for-byte unchanged from 0.1.61.

The TV at `192.168.31.188` went offline before installation. The signed APK is ready, but installation and focus navigation on the physical TV remain unverified.
