# 2026-10-30 影视探索闪退修复 0.1.23

影视探索季度列表创建每张卡片时已将其加入页面，调用方又把同一张卡片加入一次，导致 Android 抛出 `The specified child already has a parent`。修正后网络加载和缓存加载都只挂载一次。

电影详情在演员表和云资源搜索之间切换时，旧网络回调仍可能修改当前页面。详情、探索列表、人物页和云资源请求共用页面 revision；离开页面后忽略旧回调。

异常提示现在附带客户端与 Android 版本并显示完整堆栈，增加“复制报错”按钮，便于收集后续问题证据。

## 验证

- Android TV 模拟器通过三项探索流程仪器测试：复现并修复前后的重复挂载、电影三个资源来源重复开合，以及旧演员/资源响应返回后页面未被污染。
- `testReleaseUnitTest`、`lintRelease` 和 `assembleRelease` 通过；签名与既有证书摘要一致。
- 模拟器未对真实影视探索服务端执行搜索或获取；用户随后反馈已在电视测试，没有再出现此前的闪退。此为用户实测反馈，未推送或发布。
