# ETKN TV 0.1.108

- 详情页按服务器通知精确更新发生变化的电影、剧集、分集与图片，忽略无关项目；重连后检查版本补齐遗漏。
- 普通元数据更新直接替换对应文字、演员、章节、分集或版本信息，图片地址变化时才重新加载图片，减少整页刷新与闪烁。
- 更新时保留当前分集、版本、音轨、字幕、焦点及滚动位置；手动刷新与迟到请求不会覆盖较新的页面数据。

需配套已更新的 ETKN 服务端。沿用固定正式签名，可覆盖安装保留数据，支持 Android 7 / API 24 及以上；版本代码为109。本版保持原有播放决策和原生播放器依赖。

正式签名构建、115项Release单元测试、Lint零错误和7项详情独立进程仪器回归通过。已在用户电视覆盖安装并核对版本、APK哈希及启动；真实账号下的长期交互体验仍待使用确认。

应用对应源码为本仓库 `v0.1.108` 标签。原生播放器依赖、源码与重建脚本未变，继续复用 [0.1.80原生播放器源码包](https://github.com/hbq0405/etkn-tv/releases/download/v0.1.80/etkn-tv-player-sources-0.1.80.zip)，包含依赖源码与原始许可；应用按GPL-3.0发布。
