## 实现

- 版本 0.1.75 / code76，通过 `/api/tv/System/Appearance` 前台每3秒同步服务器明暗、主题色、背景图、模糊、阴影强度及透明度。按服务器缓存，账号/服务器改变后丢弃旧响应；动态换色不重建播放器、不重置焦点。卡片大小保留原账号配置。
- 常规页面共享服务器背景；首页媒体背景限制在轮播区域，媒体详情保持自己的背景。播放器仅起播等待显示服务器背景，首帧后暂停和唤出控件保留影片画面。
- 公共按钮及两处数字分集矩阵圆角，观看进度填充服务器主题色；动态主题包含文字、焦点、弹窗、开关与卡片阴影。按钮关闭原生状态阴影动画，阴影强度为0时不再额外浮起。
- 暂停显示中央暂停符号、左上角圆形头像（无头像或失败回退用户名）、右上角时钟及底部进度；唤出控件也显示身份和时间。
- 控制栏两侧留白、居中胶囊、主题色边框，底色随明暗和服务器透明度，不使用渐变。已播放及进度条边框用主题色，预缓存固定浅绿 #5CC7B0。
- 控制栏移除分辨率行，长按确认键切换左侧当前视频、音轨、字幕参数及实际解码器；短按仍执行原播放/暂停或按钮，不因长按误触。功能键切换音轨，字幕继续由控制栏按钮打开。
