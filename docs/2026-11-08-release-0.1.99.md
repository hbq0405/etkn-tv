# ETKN TV 0.1.99

本版恢复服务端转码对接，完善播放质量选择、自动转码与轨道切换。

- “质量”菜单新增自动优先原画，以及 4K · 80/60/40Mbps、1080p · 20/12/8/4Mbps、720p · 2/1Mbps。分辨率或码率任一项超过所选上限时请求转码。
- 自动模式根据电视解码能力协商播放；原画起播异常或播放中持续缓冲时请求转码，起播检测排除暂停、拖动和缓冲不足。手选质量可用于固定播放上限。
- 转码遵循服务端保存的默认质量与帧率配置；支持 HDR10 和 HEVC 10bit 的电视可由配套服务端保留 HDR，交由电视映射。
- 完善转码后的音轨、字幕选择和 HLS 字幕处理，支持保留播放位置切换轨道。
- 自动转码后的播放流就绪时，统一通过顶部通知显示“已自动转码”。缩小播放控制栏按钮，改善同屏显示。
- 修复部分 TS 媒体因 SCTE-35 数据解析导致的播放失败，并调整转码分片的等待时间。

转码需配合 2026-11-08 更新的 ETKN 服务端，并在媒体库设置中启用、保存转码配置；服务端未启用时继续原画播放。沿用固定正式签名，可覆盖安装保留数据，支持 Android 7 / API 24 及以上。

110 项单元测试通过，Release Lint 无错误，正式签名构建通过。已在用户电视覆盖安装并核对启动；用户确认相关样片的音轨/字幕切换、HDR 显示和保存保留帧率配置后的 60FPS 转码播放正常。各设备和片源的实际表现仍以使用结果为准。
