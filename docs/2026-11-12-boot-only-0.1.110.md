# ETKN-TV 仅开机自动启动，Home 返回原厂桌面 0.1.110

日期：2026-11-12

## 诊断

上一版 0.1.109 同时运行开机接收器与无障碍桌面接管。电视启动时原厂桌面会产生多次窗口切换；日志中接管服务在约 15 秒内重复启动四次 `SetupActivity`。每次都会带 `FLAG_ACTIVITY_CLEAR_TASK`，打断正在建立的首页任务，重新执行数据加载与焦点初始化。这与开机后焦点短时迟钝相符。累计 gfxinfo 的 janky frame 计数包含整段使用过程，不能单独用于判断启动帧率。

## 变更

- 按用户要求移除 Home 键接管；Home 返回 FengOS 原厂桌面。
- 删除无障碍接管服务和声明。
- 保留开机启动，但接收器默认禁用；应用设置中的“开机自动进入 ETKN TV”在本机启用后生效。
- 开机使用普通 MAIN/LAUNCHER 入口与 `NEW_TASK | RESET_TASK_IF_NEEDED`，不再清空现有任务。
- 保留上一版 IMDb 评分显示与排序、详情工作室文字按钮。
