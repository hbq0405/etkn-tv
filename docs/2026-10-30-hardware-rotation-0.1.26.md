# ETKN TV 0.1.26 硬解旋转兼容处理

日期：2026-10-30。用户授权本地修复、模拟器验证、提交与原签名 APK 构建；未推送或发布。

## 反馈与范围

用户确认 0.1.25 的软解正常，硬解问题仍在。异常设备为 L055FCN，播放页解码器信息为 OMX、旋转 270°；用户补充其他正常竖屏视频没有显示旋转角度。没有取得完整 OMX 解码器名称、系统版本或该电视的 ADB 连接，不推断芯片或厂商实现。

此前 D 盘手机样本为 720×1280、无旋转标记，模拟器系统解码基线即正常，不能用它证明带 270° 标记的真机问题已修复。

## 改动

- TvVideoRenderer 向 MediaCodec 传递零旋转的 Format 副本，输出尺寸计算也使用该副本；原始 Format 与容器旋转信息保持不变。
- 仅带旋转标记的自动模式改用 TextureView，继续使用系统解码器。无旋转标记的自动模式保持 SurfaceView，软解继续使用纹理输出。
- RotatingPlayerView 统一计算旋转后的比例，并通过纹理矩阵旋转原始帧。比例逻辑放在 PlayerView 的内容比例回调内，避免绑定播放器或后续尺寸事件覆盖已设置的比例。
- 切换视图使用同一个播放器，迁移已有 ASS 视图并恢复控制栏及焦点，不重开媒体源。解码模式的原有切换、错误恢复和生命周期保持现有流程。
- 版本 0.1.26 / versionCode 27；原生库没有变更。首页聚焦和播放结束退出沿用 0.1.25。
